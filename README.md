# Portal de Carreras Tecnológicas & Portafolio Personal - UCB
## 1. Introducción
Este proyecto consiste en el desarrollo de una plataforma web integral diseñada para representar las carreras de tecnología de la Universidad Católica Boliviana "San Pablo" (UCB), incluyendo Ingeniería de Software, Mecatrónica e Inteligencia Artificial. La plataforma funciona tanto como un punto de información para la comunidad estudiantil como un portafolio profesional que destaca la trayectoria en desarrollo Full Stack y liderazgo en la nube.

## 2. Estructura del Proyecto
  
    ├── css/                # Estilos personalizados y archivos de diseño
    
    ├── js/                 # Lógica de componentes y scripts de interacción
    
    ├── index.html          # Página principal del portal
    
    └── README.md           # Documentación del proyecto
    
## 3. Qué se hace
Se diseña una interfaz de usuario intuitiva y moderna para presentar las ventajas competitivas de las carreras de ingeniería en la UCB.

Se integra una sección de Blog técnico donde se documentan experiencias sobre arquitectura de software, IA y servicios de AWS.

Se establece una sección de contacto directa para fomentar el networking y la colaboración dentro del AWS Cloud Club.

## 4. Cómo se hace
- Diseño UX/UI: Prototipado inicial y diseño de alta fidelidad realizado en Figma.

- Desarrollo Frontend: Implementación de componentes responsivos utilizando estándares modernos de desarrollo web.

- Gestión de Versiones: El proyecto sigue un flujo de trabajo de Git riguroso, garantizando una trazabilidad detallada mediante al menos 10 commits que documentan la evolución del código.

## 5. Por qué se hace
La creación de este portal surge de la necesidad de visibilizar el talento y las herramientas tecnológicas disponibles para los estudiantes de Santa Cruz. Como AWS Cloud Club Captain, el objetivo es inspirar a otros estudiantes a través de la excelencia técnica y el liderazgo, demostrando la aplicación práctica de patrones de diseño y arquitecturas escalables en proyectos reales.
